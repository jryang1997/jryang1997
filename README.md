### Projects · 正在维护的小工具

| Project | Platform | What It Does |
| :--- | :--- | :--- |
| **[MenuBarMijia](https://github.com/jryang1997/MenuBarMijia)** | macOS Menu Bar · Windows 11 Tray · NAS | 在电脑菜单栏/托盘里顺手控制米家与 Home Assistant 设备。支持小米云扫码直连或局域网 HA 接入、按住说话语音控制与 5 秒撤销。已收录于 [`awesome-mac`](https://github.com/jaywcjlove/awesome-mac)。<br>*Native menu-bar & system-tray controller for Xiaomi Mi Home and Home Assistant.* |
| **[dsh-ascii-whales](https://github.com/jryang1997/dsh-ascii-whales)** | DeepSeek Harness Plugin | DeepSeek Harness 对话背景插件「文字蓝鲸」（致敬 [`stackedlol/ascii-sharks`](https://github.com/stackedlol/ascii-sharks)）：让你输入的文字化作在空白对话页里巡游的鲸群，支持五种鲸鱼混游、下潜浮出与磨砂阅读区避让。<br>*Procedural ASCII & shaded-cell whale school background plugin for DeepSeek Harness.* |
| **[dsh-hold-to-dictate](https://github.com/jryang1997/dsh-hold-to-dictate)** | DeepSeek Harness Plugin | DeepSeek Harness 「按住说话」语音听写插件：复用宿主内置本地语音识别模型，按住输入框说话、松手转草稿（绝不自动发送），支持组合键轻按免提与草稿防覆盖保护。<br>*Hold-to-talk & hands-free voice dictation plugin for the DeepSeek Harness composer.* |
| **[omp-bot](https://github.com/jryang1997/omp-bot)** | Windows · Web Workbench · Android | 基于 `omp` (`oh-my-pi`) 的本地多智能体协作工作台，支持单聊/群聊、共享预算下的任务委派、独立虚拟机座席与飞书/安卓伴侣端接入。<br>*Local multi-agent workbench powered by `oh-my-pi`.* |
